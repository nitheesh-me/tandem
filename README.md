# Tandem screening songs, in 4 MiB chunks

The four Tandem songs as MP3 (ID3v2.4 tags: title, artist, cover art, timed lyrics).
One folder per song, named after the file: `c00000.bin`... and `manifest.json` (root, size,
chunk_size, chunk hashes). Browsers fetch these and check every chunk's blake3 hash against
the room's root before use, so a copy from any host is safe. Generated by target/team/mirror/split
in the app repo.
